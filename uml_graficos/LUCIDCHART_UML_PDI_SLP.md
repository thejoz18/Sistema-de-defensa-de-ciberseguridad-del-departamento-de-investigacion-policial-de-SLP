# Diagramas UML para Lucidchart - PDI SLP

Estos archivos estan en formato Mermaid `.mmd`. Para editarlos en Lucidchart:

1. Abrir Lucidchart.
2. Crear un documento nuevo.
3. Usar la opcion de importar o insertar Mermaid.
4. Copiar el contenido del archivo `.mmd`.
5. Pegar y generar el diagrama.
6. Editar las cajas y conexiones dentro de Lucidchart.

Los diagramas son resumidos para que se puedan presentar sin saturar la lamina.

## 1. Diagrama general resumido

Archivo: `01_lucid_general_resumido.mmd`

Muestra el flujo completo: pantalla inicial, input, ciclos, calculos, estado, protecciones, reportes y cierre.

## 2. Metodologia de programacion

Archivo: `02_materia_metodologia.mmd`

Muestra el funcionamiento como proceso de programacion: impresion inicial, input, uso de listas, diccionarios, funciones, ciclos, condicionales, historial y salidas.

## 3. Fundamentos matematicos

Archivo: `03_materia_fundamentos.mmd`

Muestra reglas logicas, estados, cifrado Cesar, cifrado multiplicativo, cifrado reforzado y descifrado del servidor.

## 4. Algebra y trigonometria

Archivo: `04_materia_algebra_trigonometria.mmd`

Muestra entradas numericas, flujo digital, senal trigonometrica, desviacion, umbrales y graficas relacionadas.

## 5. Calculo

Archivo: `05_materia_calculo.mmd`

Muestra tasa de cambio, derivada discreta, sigmoide, segunda derivada, derivada de CPU y temperatura.

## 6. Fisica

Archivo: `06_materia_fisica.mmd`

Muestra CPU, potencia, temperatura, ventilador, refrigeracion, Bernoulli critico, consumo y grafica de temperatura.

## 7. Interaccion entre modulos Python

Archivo: `07_interaccion_modulos_por_segundo.mmd`

Muestra como `m00_pdi_slp.py` llama a los otros modulos durante cada segundo de la simulacion.

## 8. Listado tecnico

Archivo: `LISTADO_VARIABLES_FUNCIONES.md`

Incluye variables, listas, diccionarios y funciones, vinculadas con la parte del proyecto donde se usan.
